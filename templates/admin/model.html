How much of the within-session score is lookup?

Frames arrive every ~2 minutes, so neighbouring frames are near-duplicates. This probe answers each test row by copying the label of its nearest training row using untrained ImageNet features — no learning at all. The closer it gets to a trained score, the less the within-session number means.
